# Roadmap to 1.0

CUT will remain alpha until the following product outcomes are demonstrated:

- faster bounded preview iteration on representative projects;
- clean installation and first render on every declared platform;
- stable language, IR, lock, and package compatibility policies;
- complete nonlinear editing, audio, captions, responsive output, and OTIO flows;
- maintained examples for documentary, product, dialogue, education, and social edits;
- independent-user authoring feedback and documented migration support;
- a signed, reproducible release process with an explicit support matrix.

The roadmap does not lower correctness or security boundaries to meet a date.
Specific implementation experiments and private production evidence are tracked
outside the public source repository.
