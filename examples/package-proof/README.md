# Local package execution proof

This project imports `ImpactCard` from the sibling
`@cut-proof/impact-cards` package. The expected proof path is:

1. resolve and verify `cut.package.json` plus its local dependency graph;
2. generate `cut.package.lock` through the public package CLI;
3. check the imported signature derived from the package's parsed CUT source;
4. lower the package component body into typed CutAVIR with package provenance;
5. render the dark background, warm card, coral rail, and coral circle through
   the ordinary reference compositor.

The checked-in lock is generated by `cut package update`, then verified before
every check/build/render. A resolver-only or hand-authored lock is not evidence
of package execution.
