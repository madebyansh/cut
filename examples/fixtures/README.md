# Redistributable fixture assets

`Geist-Regular.ttf` is an unmodified fixed-instance Geist font used by CUT's
public text examples. Its SHA-256 is
`bde046ddd9f20be35b0bd56cc79eb752b967fb6661a3fe76cb067bb09f871d76`.
The font's name table identifies version 1.800 and copyright 2024 The Geist
Project Authors. The checked-in bytes are identical to the copy distributed in
Next.js 16.2.10 at `dist/compiled/@vercel/og/Geist-Regular.ttf`.

The adjacent `Geist-LICENSE.txt` is byte-for-byte the upstream Geist
`LICENSE.txt` at commit `10dc7658f13c38a474cde201bb09a4617267545b`, retrieved
from
<https://github.com/vercel/geist-font/blob/10dc7658f13c38a474cde201bb09a4617267545b/LICENSE.txt>.
Its SHA-256 is
`930853ee1daa68554d9e35c8a9175affb74f699fad9a5da6ee5ebe76379d9137`.
It is the SIL Open Font License 1.1 and must remain beside the font in every
redistributed CUT artifact.
